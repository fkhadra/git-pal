# Menu bar, Dock and updates

## Menu bar

Git Pal's icon sits in the menu bar on macOS, in the system tray on Windows and Linux. Its menu:

- **N agent reviews running** and **N reviews waiting on you**, when there are any. Both open the review window.
- **Show Git Pal** opens the palette.
- **Reviews** opens the review window.
- **Settings**.
- **Quit Git Pal**.

A review waits on you when it's reviewed or has notes, isn't submitted, and no agent is running on it.

On macOS, the icon shows how many reviews wait on you, and a spinner while agents run. On Linux, the tray shows the count.

## Dock

On macOS, Git Pal shows in the Dock only while the review or settings window is open. Its badge counts the reviews waiting on you.

## Updates

Git Pal checks for updates when it starts, then every hour, and downloads them in the background. When one is ready, an **Update** button appears in the palette's search bar. Click it or press <kbd>⌘</kbd> <kbd>U</kbd> (<kbd>Ctrl</kbd> <kbd>U</kbd>) to install it and restart.

Nothing is installed until you ask.
